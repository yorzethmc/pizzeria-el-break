# Prompt Maestro para IA (Plantilla)

Este proyecto ahora es una **Plantilla Base**. Si necesitas pedir a una IA que modifique este proyecto, puedes usar un prompt similar a este:

```text
Actúa como desarrollador web frontend.
Tengo un proyecto de React/Vite que funciona como plantilla para un sistema de pre-order por WhatsApp.
El proyecto utiliza una arquitectura por capas en los datos: Categorías -> Productos -> Opciones -> Extras.

Quiero que modifiques este proyecto para adaptarlo al negocio "[Nombre de tu Negocio]". 
Por favor:
1. Actualiza `src/menuData.js` con las siguientes categorías y productos: [lista de productos].
2. Cambia los colores principales en `src/styles.css` para que sean [tus colores].
3. Actualiza las variables de configuración en `src/App.jsx` con el número de WhatsApp [tu número].

Asegúrate de mantener el diseño limpio y responsive.
```
