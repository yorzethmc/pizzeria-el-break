# Preorder HTML - Instrucciones para IA

Este proyecto no contiene todavia la aplicacion final. Es una carpeta de instrucciones para que una IA construya mas adelante un sistema de pre-order desde cero.

La version inicial debe ser un solo archivo:

```text
index.html
```

Ese archivo debe incluir HTML, CSS y JavaScript en el mismo documento. No usar React, Vite, Next.js, backend, base de datos ni dependencias externas en la primera version.

## Objetivo

Crear una aplicacion web simple para tomar pedidos de pre-order.

Al cliente solo se le debe pedir:

- Nombre completo.
- Direccion de entrega.
- Productos que quiere.
- Cantidad de cada producto.

La aplicacion debe permitir ver productos, seleccionar cantidades, enviar el pedido y ver una confirmacion clara.

## Archivos importantes

- `PROMPT_MAESTRO_PARA_IA.md`: prompt principal que se debe entregar a la IA constructora.
- `ESPECIFICACION_FUNCIONAL.md`: requisitos funcionales de la aplicacion.
- `PROTOCOLO_AUTOGESTION_IA.md`: reglas para que la IA se organice, documente avances y registre problemas.
- `referencia/ESTRUCTURA_FINAL_ESPERADA.md`: estructura esperada cuando se construya la aplicacion.
- `bitacora/PROGRESO.md`: la IA debe actualizarlo con avances.
- `bitacora/PROBLEMAS.md`: la IA debe registrar bloqueos, errores o dudas.
- `bitacora/CORRECCIONES.md`: la IA debe registrar cambios hechos para corregir fallos.
- `bitacora/DECISIONES.md`: la IA debe registrar decisiones tecnicas o de diseno.

## Instruccion corta para la futura IA

Lee todos los documentos de esta carpeta antes de crear codigo. Luego construye la aplicacion completa en un solo `index.html` y actualiza la bitacora mientras trabajas.
